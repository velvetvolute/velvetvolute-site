# Homepage overrides (Velvet Volute)

> These rules override MASTER.md for the homepage only.

## Why overrides
- MASTER.md picked "Liquid Glass" as the style. That style is meant for Apple-platform
  app chrome, not a boutique storefront. A narrower `--domain style` search returned
  **Editorial Grid / Magazine**, which suits a curated collection. Use that.
- MASTER.md picked a neutral stone/gold palette. Velvet Volute's existing identity is
  wine and gold, so keep the brand hues and use the master's ivory as the light surface.

## Style: Editorial Grid / Magazine
- Asymmetric grid, print-inspired typography, generous whitespace (density 3/10)
- Pull quotes, small caps labels, numbered sections, thin rules instead of boxes
- Subtle motion only (motion 3/10): 300-400ms fade-up, 8-16px offset, reduced-motion respected

## Typography
- Headings: Cormorant Garamond (existing brand serif; master suggested Cormorant)
- Body: Montserrat 400/500 (from master), 16px base, 1.6 line height

## Keep from MASTER.md
- Pre-delivery checklist: SVG icons only, visible focus, 4.5:1 contrast,
  reduced motion, responsive at 375 / 768 / 1024 / 1440
